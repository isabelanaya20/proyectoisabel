CLASE 9 de noviembre – MATPLOTLIB EN PYTHON

1. ¿Qué es Matplotlib?

Matplotlib es una biblioteca de Python que permite crear gráficas y representar datos de manera visual. 
Se utiliza para analizar información y facilitar su interpretación.

2. ¿Qué es Pyplot?

Pyplot es una herramienta de Matplotlib que permite crear gráficas mediante funciones sencillas.

3. Importación de bibliotecas

Para trabajar con gráficas se utilizan las siguientes instrucciones:

import matplotlib.pyplot as plt
import numpy as np

- matplotlib.pyplot: permite crear y personalizar gráficas.
- numpy: permite trabajar con datos numéricos y arreglos.

4. Pasos para crear una gráfica

- Organizar los datos.
- Seleccionar el tipo de gráfica.
- Personalizar el título, las etiquetas y los colores.
- Mostrar la gráfica utilizando plt.show().

5. Tipos de gráficas

Se trabajaron diferentes formas de representar información, como:

- Gráficas de barras.
- Gráficas circulares o de torta.
- Gráficas de líneas.

6. Gráficas circulares

Se utilizó la función plt.pie() para representar datos en porcentajes.

Algunos de sus elementos son:

- labels: permite colocar los nombres de las categorías.
- autopct: permite mostrar el porcentaje de cada parte.
- plt.title(): permite agregar un título.
- plt.show(): permite visualizar la gráfica.
